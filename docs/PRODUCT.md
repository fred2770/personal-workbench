# PRODUCT - 产品需求基线

## 产品定位
个人工作台用于统一处理项目、任务、问题、Bug、需求、现场反馈、速记、附件和工作记录。

核心闭环：Quick Capture → Inbox → Project / WorkItem / Memo → 处理 → Attachment / Activity → 完成与验证 → 归档 → 搜索。

## 首版页面
- Dashboard
- Quick Capture
- Inbox
- 项目列表 / 项目详情
- WorkItem 列表 / 详情
- Memo
- 全局搜索
- 设置

## WorkItem 类型
TODO、ISSUE、BUG、REQUIREMENT、FOLLOW_UP、SITE_FEEDBACK。

## 快速记录
尽可能少的操作完成标题、正文、图片、文件、类型、项目、标签的录入。

## 图片与附件
支持文件选择、剪贴板粘贴、预览、删除，并与记录绑定。

## 项目聚合
项目详情聚合待办、问题、Bug、需求、现场反馈、Memo、附件、Activity。

## 搜索
目标支持 Ctrl+K 搜索 Project、WorkItem、Memo。

## 非首版
多租户、复杂权限、审批流、微服务、Kubernetes、IM。

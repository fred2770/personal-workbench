# UI-SPEC - 界面规范

目标：Linear 效率感 + Vercel 克制感 + Bento Grid 信息组织。

## 原则
- 专业、简洁、高信息密度、快速操作、统一
- 桌面左侧主导航 + 主工作区；必要时右侧详情面板/抽屉
- Quick Capture 始终容易触达
- 移动端重点保证快速记录、待办、问题、项目
- 深蓝黑/石墨黑为主要深色方案，蓝紫可作强调色
- 毛玻璃、渐变、发光仅辅助
- 常见操作尽量 1~2 步完成
- 删除等危险操作确认
- 明确空状态、加载态、错误态
- 图片粘贴后不能破坏文本输入焦点
- 键盘操作友好

统一组件：Button、Input、Select、Modal、Drawer、Table/List、Badge、Tag、Empty、Loading、Toast、Form、Attachment。
